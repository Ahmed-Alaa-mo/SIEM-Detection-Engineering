# SIEM Detection Engineering, Alert Triage & SOC Operations

## Project Overview
This project focuses on designing and documenting a Security Information and Event Management (SIEM) workflow for security monitoring, threat detection, alert triage, and SOC operations.

## Project Objectives
- Understand SIEM architecture and log onboarding.
- Develop and test security detection rules.
- Analyze and triage security alerts.
- Build SOC dashboards and track operational metrics.
- Explore threat intelligence, MITRE ATT&CK mapping, SOAR playbooks, and AI-assisted workflows.

## Tools and Technologies
Planned tools include:
- Wazuh
- Splunk or ELK Stack
- MITRE ATT&CK
- Ollama

*The final tools used will be documented as the project progresses.*

## Project Phases

### Week 1: SIEM Architecture & Log Onboarding
Plan the SIEM architecture, identify log sources, and document log normalization.

### Week 2: Correlation Rules & Detection Use Cases
Develop and test detection rules for scenarios such as brute-force attempts and suspicious logins.

### Week 3: Dashboards, Metrics & Alert Triage
Document SOC dashboards, operational metrics, and alert investigation workflows.

### Week 4: Threat Intelligence, SOAR & AI-Assisted SOC Workflow
Explore threat intelligence enrichment, MITRE ATT&CK mapping, SOAR playbooks, and AI-assisted alert analysis.

## Deliverables
Project documentation, architecture diagrams, detection rules, test results, dashboards, triage reports, and final documentation will be added as they are completed.
